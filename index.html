User Guide

මේ app එක පාවිච්චි කරන විදිය පියවරින් පියවර ඉගෙන ගන්න. 👑

Sign in කරන්න

උඩ දකුණේ තියෙන "Sign in with Google" button එක ඔබන්න. ඔයාගේ Gmail එක තෝරන්න. එතකොට ඔයාගේ data ඔයාගේම Google Drive එකට save වෙන්න පටන් ගන්නවා.

දවසේ කාලසටහන හදන්න

Daily Schedule කාඩ් එකේ ඕන activity එකක ✏️ pencil icon ඔබලා time, title, note, icon, color edit කරන්න. + එකෙන් අලුත් ඒවා add කරන්න. දැන් වෙලාවට කරන්න ඕන activity එක auto highlight වෙනවා.

පුරුදු track කරන්න

Daily Checklist එකේ හැම පුරුද්දක්ම tick කරන්න. Weekly Habit Matrix එකේ dots ඔබලා දවසේ තත්වය දාන්න (🟢 Done / 🟡 Partial / 🔴 Missed).

Pomodoro Timer පාවිච්චි කරන්න

Focus Timer එකේ Start ඔබන්න. මිනිත්තු 25ක් එකදිගට වැඩ කරන්න. Timer ඉවර වුනාම confetti + notification එකක් එයි. ඊට පස්සේ මිනිත්තු 5ක break එකක් ගන්න.

Journal ලියන්න

Daily Reflection එකේ දවස ගැන ලියන්න. හොඳට කරපු දේ, ප්‍රශ්න, ලබන දවසේ improve කරන්න ඕන දේ. Save කරන්න අමතක කරන්න එපා.

Backup ගන්න

Cloud Backup එකේ Backup Now ඔබන්න. Auto-backup checkbox එක tick කරන්න — හැම විනාඩි 5කට වරක් auto save වෙයි. අලුත් device එකකට යනකොට Restore ඔබන්න.

AI Coach අහන්න

Sidebar → AI Coach එකට ගිහින් උදේ නැගිටින්නේ කොහොමද, study focus වැඩි කරගන්නේ කොහොමද වගේ ප්‍රශ්න අහන්න. සිංහලෙන් හෝ English වලින් ලියන්න පුළුවන්.
